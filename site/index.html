Install symapper

npx symapper .

macOS and Linux. Needs git and Node 18+. Other installs.

Ranked map: each path: block lists signatures, best match first.

How it works

  1. Read tracked files
  2. Find definitions and uses
  3. Build a file graph
  4. Rank toward your focus
  5. Trim to the token budget
  6. Print the map

Ranking details →

Use it with coding agents

  1. Pick focus words from the task.
  2. Run the map once at the start.
  3. Read the top files.
  4. Still search with rg; the map can miss files.
Before exploring the repository, run:
npx symapper . --tokens 1500 --focus <word from the task> --focus <another word>
The map is a starting point: read what it points to, then still search the code (rg/grep).
It can miss files.

A focused view

  • Ranked around your focus

    --focus path|word

  • Fits your token budget

    --tokens N

  • Local and read-only

    No LLM. No daemon.

  • Six languages

    TypeScript, JavaScript, Python, Go, Rust, Swift

Point it at your task

Paths, identifiers and plain words all work. Flags and focus →

symapper . --focus src/render.rs --focus render_prefix --tokens 1000

Local by design

No network while mapping. It never runs repository code or hooks. Cache and safety →
